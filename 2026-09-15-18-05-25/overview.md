# 项目概览：全天录音 · 云端转写总结系统

## 完成内容

为华强北方形安卓表（Noemie OS / 安卓 9）打造了一套「全天录音 → 充电上传网盘 → 云端转写总结 → 邮件推送 + 网页查看」的完整系统，包含三部分交付：

### 1. 手表端 Android 应用（`all-day-recorder/`）
- 前台服务全天录音：AAC 16kHz 单声道 32kbps，每 10 分钟自动切段 `.m4a`（音质/分段时长可配置）
- 完整 C 端交互：**开始 / 暂停 / 继续 / 停止录音**、实时状态（时长、今日段数、待上传、占用、上次上传结果）、录音文件列表（查看/删除/清空）
- 上传带进度通知与结果反馈；支持充电自动上传、仅 WiFi 上传、开机自启（均可开关）
- 设置页含「电池优化白名单」一键保活引导
- **息屏录音保障**：前台服务 + 部分唤醒锁 + 电池白名单检测提示
- **保护策略**：低电量自动停止、存储占用告警/自动清理最旧、看门狗自愈（服务被杀自动拉起）、上传失败重试 + 原因提示
- 纯 Android SDK、零第三方依赖，可离线构建（`minSdk 28` / `targetSdk 28`）

### 2. 云端转写总结流水线（`cloud-pipeline/`）
- 从网盘读取模型设置 `_settings.json`（网页端可改），覆盖本地默认
- 从 PikPak WebDAV 拉取当天录音（PROPFIND 列目录 + GET 下载）
- 语音转写：默认 **DashScope 文件转写**（`paraformer-v2`，**说话人分离 + 时间戳**），走「上传临时存储 → 异步转写 → 下载结构化结果」；可切换 OpenAI 兼容接口（纯文本降级）
- 逐字转写原文保存到网盘 `transcripts/YYYY-MM-DD.json`（带 speaker + 起止时间）
- 用 `/chat/completions` 汇总成每日总结，写回网盘 `summaries/YYYY-MM-DD.md` + QQ 邮箱 SMTP 发送
- 状态存 `_state.json`，幂等可断点续跑；超长文本自动分段总结
- 支持阿里云 FC / Serverless Devs / Docker / 常驻服务器四种部署方式
- 已通过 Python 语法与逻辑自检

### 3. 网页控制台（`web/`，部署在你的服务器）
- Flask 单体应用 + Docker 部署，登录密码鉴权
- 三标签：**模型设置**（读写网盘 `_settings.json`，含模型下拉选择 + 说话人分离开关）、**总结历史**（列表）、**日历**（月视图高亮有总结的日期）
- 详情页支持**查看逐字转写原文**（带说话人 + 时间戳的对话流）
- 无数据库、无状态，与云端流水线通过 PikPak WebDAV 共享数据
- 已通过登录/鉴权/转写接口冒烟测试

## 关键决策

1. **上传用 PikPak WebDAV**（而非百度/阿里网盘开放 API）：协议简单可靠，用户已有 PikPak 会员。已核实 PikPak WebDAV 为会员功能、支持上传，但需用户手动开启并自测写入权限。
2. **转写总结放云端独立流水线**（阿里云 FC 定时触发），手表只负责录音+上传，降低手表功耗与算力负担。
3. **模型可自定义 + 可下拉选择**：网页端提供预设模型下拉（转写 paraformer-v2/sensevoice-v1 等，总结 qwen-plus/qwen-max 等）也可自定义输入；网页端设置的优先级高于 config.yaml。
4. **转写升级为结构化**：默认 DashScope 文件转写，输出「说话人 + 时间戳 + 文本」；逐字原文持久化到网盘供网页查询。
5. **数据总线用 PikPak WebDAV**：手表、云端流水线、网页端三方共享同一网盘目录，模型设置、总结、转写原文都存网盘，网页端无需数据库。
6. **通话录音明确放弃**：安卓 9 + Noemie OS 下通话录音不现实，仅做环境录音。

## 待用户完成的操作

1. 用 Android Studio 构建 APK 并侧载到手表（ADB / 手表直接装 / 手机推送工具）
2. 在 PikPak 网页版开启 WebDAV，拿到地址/用户名/密码
3. 阿里云百炼开通并创建 API Key
4. QQ 邮箱开启 SMTP 获取授权码
5. 填好 `cloud-pipeline/config.yaml` 并部署到阿里云 FC
6. 把 `web/` 部署到自己的 Linux 服务器（`docker compose up -d`），填 WebDAV 与访问密码

## 已知限制

- 通话录音不可用；PikPak WebDAV 需会员；Noemie OS 保活需手动关闭省电限制；转写按量计费。
- **说话人分离 ≠ 身份识别**：模型只能区分「说话人 1/2/3」，无法知道具体是谁（需另建声纹库）。
- 网页端无多用户，单密码登录；建议加 HTTPS 反代。
